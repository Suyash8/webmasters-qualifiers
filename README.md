# 🎬 BollyMasala

**BollyMasala** is a simple Bollywood-themed movie recommender app built for the **WebMasters Qualifiers** frontend hackathon. It delivers basic movie suggestions with a clean UI and smooth experience.

## 🚀 Tech Stack

- [Next.js](https://nextjs.org/)
- [shadcn/ui](https://ui.shadcn.com/)
- [Tailwind CSS](https://tailwindcss.com/)

## 📦 Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/bollymasala.git
cd bollymasala
```

2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

4. Open `http://localhost:3000` to view it in your browser.
